# Погода

Сайт: https://birusvox.github.io/weather-app/

Погода по широте и долготе. Данные приходят из Open-Meteo, точка отмечается на карте OpenStreetMap.

## Что есть в приложении

- Форма с полями «Широта» и «Долгота» и кнопка «Показать погоду».
- Проверка ввода: пустое значение, не число, широта вне диапазона от -90 до 90, долгота вне диапазона от -180 до 180. Десятичная запятая тоже принимается.
- Запрос погоды через `fetch` и `async/await`.
- Температура и состояние: ясно, облачно, туман, дождь, снег, гроза. Для каждого состояния своя картинка, ночью при ясной погоде показывается луна.
- Дополнительно: скорость ветра, влажность, местное время и часовой пояс.
- Карта с меткой по введённым координатам.
- Можно добавить несколько карточек и удалить любую.
- Библиотеки и фреймворки не используются.

## Как открыть

Готовый сайт: https://birusvox.github.io/weather-app/

Локально через nginx:

```
docker build -t weather-app .
docker run --rm -p 8080:80 weather-app
```

После запуска приложение доступно на http://localhost:8080.
